## Codex Strategic Read: Auto-Connect Vision

The operator asked whether WD solvers can be prepared to connect automatically
in anyone's environment. Codex position:

- The vision is correct, but full zero-config auto-connect is not a single
  ENG follow-up PR.
- v3.x can ship safe first slices toward it.
- Full autonomous discovery across arbitrary homes/factories is closer to a
  v4-scale substrate if it includes scanning, protocol negotiation, credential
  flows, writes, and cross-vendor automation.

Use layered capability levels:

- L0: manual local artifact / explicit URL / explicit file path.
- L1: explicit operator allowlist for private LAN read-only HTTP endpoints.
- L2: passive or low-risk discovery inventory, still no reads without operator
  confirmation.
- L3: connector fingerprint to normalized observation schema to
  knowledge/persona interpretation.
- L4: writes/effects only behind separate operator approval and RCO gate.

Guardrails not to compromise:

- private/loopback hosts denied by default
- explicit operator opt-in per host/CIDR/protocol
- read-only first; no writes in the same cluster
- no credential capture or credential headers by default
- no broad port scanning by default
- every LAN request logged/auditable with endpoint, risk class, and solver case
- fail closed on unknown schema, stale readings, unit ambiguity, missing
  thresholds
- separate approval model for any external_effect/write case

The `knowledge/` tree should be the interpretation layer, not the discovery
layer. Discovery/connectors should produce normalized observations with units,
timestamp, source, confidence, and schema version. Persona/knowledge maps those
observations to thresholds/advice. Do not let knowledge files initiate network
access.

Smallest safe first step toward the vision:

- AIR-01 read-only first slice with explicit allowlisted private-LAN URL
  transport.
- Digheran-shaped JSON fixture/parser.
- Air-quality observation normalizer.
- `knowledge/air_quality` threshold interpreter.

This proves LAN data to knowledge interpretation without opening broad
auto-discovery behavior.
