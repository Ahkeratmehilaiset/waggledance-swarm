# Regression ledger

This file is a **rendered** view of `state/regression_ledger.json`.
Refresh by calling
`Write-WaggleRegressionLedgerMarkdown` (defined in
`orchestrator/lib/RegressionLedger.ps1`) or by running an iteration
that touches the ledger — the dynamic epoch controller (REL-013)
keeps it up to date.

The runtime data file (`state/regression_ledger.json`) is gitignored
because it changes per epoch. This rendered markdown is committed
so PR reviewers can see the trajectory at any commit point. When
the ledger is empty, the sections below say "_None._".

The schema lives at `schemas/regression_ledger.schema.json`.
