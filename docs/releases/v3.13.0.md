# v3.13.0 - Release Notes (substrate-only candidate)

* Release target: **v3.13.0** substrate-only landing.
* Posture: **substrate-landed, not activated.** No package version bump,
  no stable tag, no Docker / `:latest` promotion. v3.13.0 introduces the
  runtime substrate for the Shadow -> Hybrid -> Autonomous solver
  migration; it ships in `main` but no real-data activation has happened.
* Previous stable: `v3.8.0` (2026-05-04). v3.9-v3.12 remain prereleases.
* Operator-facing flow tested under: dry-run only (HOME +
  COTTAGE runbooks) with synthetic data; no operator data was ingested
  during Sprint 1.

This document is the substrate landing surface. It is generated from the
landed PRs through main HEAD `6d2e59b` (2026-05-13). Numbers, event
types, schema fields, and PR references are measured against the
committed code, not aspirational.

## Highlights

* **Sprint 1 runtime substrate complete in three waves + polish.** 14
  PRs merged via mutual RCO between Claude and Codex with 9 round-2
  cycles catching real fail-closed bugs:
  - Wave 1 (`fed8d35`): WriteRCOGate v1, CredentialVault, ANTI-001..007
    catalog, BehaviorCapture + ShadowRunner, DivergenceAnalyzer + INST-G09,
    Band B inventory generators, savepoint PS5.1 ASCII fix.
  - Wave 2 (`cff15f5`): SolverProvenance signing chain, DEF defaults
    lock-in, WriteRCOGate WRT-003 verify_solver_provenance wireup +
    SCH-005 SolverCandidateManifest schema.
  - Wave 3 (`a69e925`): sim_orchestrator streaming-mode instrumentation,
    AutoFixLoop v1 (event consumer + repair proposer).
  - Polish (`6d2e59b`): HOME + COTTAGE dry-run runbooks with schema-drift
    regression test, ShadowRunner baseline fail-closed signal.
  - Release-surface docs (this PR): CHANGELOG + release notes +
    readiness section + machine-derived event-surface audit script
    (`tools/audit_v3_13_0_event_surface.py`).
* **Single write choke point.** Every internal-memory, local-artifact,
  and external-effect write classifies through `WriteRCOGate.route()`
  with 12 audit event types, 5 active stop conditions, and a
  fail-closed default for ambiguous classification. WRT-003 external
  effects require resolved StateInfo, `write_modes_allowed`
  enforcement, RecoveryCapsule rollback plan, peer RCO, operator scope
  policy, and (when a solver_candidate_id is in payload) a valid
  `verify_solver_provenance()` result. Missing any of these denies
  the write.
* **SolverProvenance signing chain with fail-closed verification.**
  Owner + peer + (for WRT-003 / sensitive-domain) operator signatures
  on a sha256-canonical manifest. Quarantine (auto-reversible) and
  permanent revoke (operator-driven, one-way) tracked as distinct
  states. Auto-quarantine triggers after 5 consecutive runs with
  divergence_score >= 0.40. Re-signing a REVOKED candidate is refused;
  reactivation requires a fresh manifest sha256.
* **ANTI-001..007 invariant catalog with module-scope regex.** Seven
  invariant checks (bulk-read-window, text-date-sort, parallel-writers,
  credential-in-repo, parser-no-silent-fail, api-rate-limit,
  memory-append-only). ANTI-002 handles uppercase column metadata +
  table-qualified ORDER BY + quoted identifiers. ANTI-004 scans for
  14 credential patterns with vault://+${ENV} allowlist (space-masked
  to avoid retriggering on the masked region).
* **CredentialMaterial cannot leak via logging / pickle / copy /
  comparison.** `__repr__` redacted, `__str__` redacted, `__reduce__`
  refuses pickle, `__copy__` / `__deepcopy__` raise, `__eq__` returns
  NotImplemented. `reveal(purpose=...)` always audits via
  `auth.material_revealed`; vault binds emitter at material
  construction so no caller can bypass auditing. Calling `reveal()`
  with neither bound nor passed emitter raises RuntimeError.
* **BehaviorCapture honors sensitive-class retention floors.** secret
  -> hash-only persistence; raw stdin/stdout/stderr payloads NEVER
  reach `persist_artifact` for secret class; opaque refused at the
  gate. Stdin payload capture requires both `ToolDescriptor.capture_stdin=True`
  AND a valid single-use consent token.
* **DivergenceAnalyzer reports real field counts.** Five format
  comparators (json, csv, sql_diff, filesystem, text), seven template
  family severity tables (SOLV-001..007), `ComparisonResult(details,
  n_compared, n_matching)` with real numerator and denominator.
  Severity-weighted score normalised over the total comparable
  surface, not just the diverging subset. INST-G09 acceptance gate:
  non_divergent_pct >= 95% AND no critical-severity diffs.
* **ShadowRunner fail-closed at every boundary.** No WRT-003 from
  candidate. No write to operator-owned StateHandle. Wall-time +
  cost-budget enforcement. Baseline subprocess non-zero exit -> abort
  with `shadow.baseline_failed` (no `shadow.run_completed` emit).
* **AutoFixLoop with single-instance lease + per-event cursor chain.**
  Stale lease takeover (`lease_ttl_seconds`, default 3600) emits
  `auto_fix_loop.lease_stale_takeover` audit event with the
  superseded instance ID. Sensitive (DOM-015, DOM-021) and
  operator-only (PER-*) domains refuse repair. WRT-003 routes through
  WriteRCOGate; WRT-001 / WRT-002 auto-apply only after gate approval.
  Dry-run mode emits `repair_proposed` and never executes.
* **DEF-001..006 default constants locked in.** Embedding model
  `intfloat/multilingual-e5-small` (384 dims, 134 MB, CPU), retrieval
  sim_threshold=0.58 / top_n=8, action TTL=14d with locale noise
  filters (fi/sv/de), sync overlap=7d, shared-prod max_workers=3 +
  request_delay=0.15s, DB defaults ISO-8601 + WAL + UNPARSED sentinel.
* **HOME + COTTAGE dry-run runbooks published** under
  `docs/runbooks/v3_13_0/`. Schema-drift regression test mirrors the
  Step-3 SolverCandidateManifest example from each runbook and
  validates it against `solver_candidate_manifest.schema.json` so the
  doc cannot silently diverge from the schema. Explicit "no CLI in
  v3.13.0" preamble + API-level Python pseudocode replaces any
  copy-pasteable command that would silently no-op.
* **292 v3.13.0-bracketed tests pass.** 9 module-test files under
  `tests/v3_13_0/` (243 tests), 3 contract-test files under
  `tests/contracts/` (35 tests), plus the sim_orchestrator
  retrospective + streaming tests under `tests/tools/` (14 tests).
  Codex confirmed final post-merge sanity on `6d2e59b`.

## Explicit non-deliverables (Sprint 2+)

The following are **NOT** in v3.13.0; do not claim them in release
communication:

* **No CLI / `python -m` entry points** for any
  `waggledance.core.v3_13_0.*` module. `tools/sim_orchestrator.py`
  retains its existing retrospective CLI but adds NO new CLI flag
  for streaming mode. Operator invocation is API-level Python.
* **No real-data activation.** All Sprint 1 runs are dry-run with
  synthetic data. Activation requires Sprint 2+ components
  (`DocIngest`, `SolverSynthesizer`, real ProfileConfig under a
  policy that explicitly allows external_effect writes).
* **No DocIngest, SolverSynthesizer, or SituationRoom.** These are
  Sprint 2 deliverables and are referenced as forward-pointers in
  the runbooks.
* **No cryptographic / hardware-key operator signatures.** Operator
  signature in v3.13.0 is captured via the bridge event mechanism
  (`signing_role=operator` payload), not via Yubikey / GPG / TPM.
  Cryptographic hardening is v3.14.0+.
* **No autonomous daemon harness for AutoFixLoop.** v3.13.0 ships
  `run_once(cursor)` for operator-driven invocation; long-running
  daemon process management is operator-managed.
* **No Stage-2 cutover.** Stage-2 cutover remains specified in
  `docs/architecture/STAGE2_CUTOVER_RFC.md` and is NOT executed
  in v3.13.0.

## Stable promotion gate (v3.13.0 -> stable)

**Not active.** v3.13.0 is a substrate-only landing; stable
promotion requires:

* Real-data activation evidence (Sprint 2+).
* Operator-signed activation of at least one solver candidate
  (HOME or COTTAGE).
* INST-G09 95%-non-divergence window over a shadow corpus that
  contains operator-real (not synthetic) baseline.
* Operator decision to promote.

None of these are in scope for v3.13.0. The R22.5 soak window from
the v3.12.0 candidate remains the operative gate for the next
stable cut.
