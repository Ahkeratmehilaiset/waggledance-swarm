# v3.12.0 — Release Notes (candidate)

* Release target: **v3.12.0** stable.
* No earlier than: **2026-05-24** (per R22.5 soak / promotion gate;
  see `docs/release/RELEASE_READINESS.md` and `tools/check_release_gate.py`).
* Posture: prepare-now-candidate, do not publish stable until the
  soak window completes and operator confirms the D1 PII-history
  decision.
* Previous stable: `v3.8.0` (2026-05-04). v3.9–v3.11 remain prereleases.
* Docker registry: GHCR primary; no Docker Hub mirror yet.

This document is the candidate release surface. The historical sections below
describe the May substrate. The September 10 candidate composes PR #1673
(`459d7bf8`), PR #1674 (`f002360f`), and the preserved corrections
`fdbd0c3d` and `9856b40c` at `1a6598c7`. This is a candidate branch,
not a claim that these changes have merged to main or shipped as stable.
Numbers and PR references are measured / observed, not aspirational.

## Highlights

* **Reproducible dependency installation** — PR #1673 refreshes the lock,
  explicitly pins the platform-specific Torch dependency chains and adds
  native pip-resolution CI validation. Chroma is an optional `[chroma]`
  extra; the legacy memory entrypoint reports a clear installation requirement
  when it is absent. No package is installed automatically.
* **Source-bound release evidence** — PR #1674 defines a source subject `S`
  followed by an evidence-only commit limited to the carrier and five named
  sidecars. Docker evidence is evaluated against its declared subject, and
  the isolated live-gate child carries the Axis verification closure.
  These are evidence reproducibility improvements, not runtime capacity claims.

* **Audit-fix series complete** — coordinated multi-agent (Claude Code +
  OpenAI Codex) parallel skeptic audit produced 88 findings; the
  operator-approved D1/D2/D3 decision wireups + 28 H-numbered fixes
  landed across PRs #237–#277.
* **EIG2 M0 + M1.0 + substrate 55/55** — the entire 50-leaps menu plus
  L51–L54 plus L60-NEW plus the strategic capstone (ADR-062) are pinned
  in `main` as machine-checkable ADR + JSON contract + contract test
  trios. 55 ADRs (ADR-010 through ADR-062) carry the architectural
  intent forward without prematurely landing runtime code.
* **L54-reframed: 99.6 % cold-boot reduction** — `bind_executors()`
  rewritten from 23 eager `try/except` adapter constructors to a
  lazy-factory registry (PR #340). Bench: 6855 ms median → 27 ms
  median across the capability loader. `capability_loader.py` shrank
  488 → 145 lines (-70 %). First `get_executor()` call triggers
  `importlib.import_module` + adapter `__init__`; everything else is
  pure registration.
* **Release gate / soak evidence guardrail** — `tools/check_release_gate.py`
  (PR #292) now fail-closes any stable promotion that lacks
  `waggledance.release_soak.v1` evidence covering CI / Profile S /
  security / Axis / Docker / anti-claim fields. 336-hour soak window
  is enforced before stable can ship.
* **AI-Assisted Bootstrap Kit (strategic capstone, ADR-062)** —
  contract + first GADGET-profile kit content seeded
  (`configs/bootstrap_kit/GADGET.yaml`, signature-hash-anchored,
  pending operator sign-off per BSK-007).
* **Magma EventLog perf-guard threshold** — relaxed 50 → 500 ms
  (PR #341) to accommodate GHA hosted-runner variance while still
  catching genuine O(N) regressions; unblocked substrate landings
  #318 and #326.

## Tooling additions

* **`tools/check_lock_resolves.py`** — rejects incomplete dependency locks
  through native pip resolution on the CI runner.
* **`tools/run_release_torch_lock_evidence.py`** — produces Torch lock
  evidence; the proposed scope update still needs its own operator signature.
* **`docs/release/RELEASE_EVIDENCE_COMMIT_CONTRACT.md`** — documents the
  evidence-only commit shape enforced by boundary readiness, while retaining
  the live gate's content checks.
* **Privacy collection consistency** — the collector reuses the verifier's
  strict privacy predicate, accepts qualifying actual test counts, rejects
  historical-only or incomplete markers, and reports unreadable receipts
  as unknown. This closes a collector/verifier disagreement.
* **Safe YAML loader clarity** — the tunnel registry explicitly names
  `yaml.CSafeLoader` or falls back to `yaml.safe_load`, preserving safe
  runtime behavior while making it visible to static analysis.

* **`tools/check_release_gate.py`** — release promotion gate. Parses
  `docs/release/RELEASE_READINESS.md`, requires
  `waggledance.release_soak.v1` evidence, fail-closes until soak
  window completes + CI / Profile S / security / Axis / Docker /
  anti-claim fields pass.
* **`tools/sim_orchestrator.py`** — read-only replay harness for
  bridge events. Computes lane balance, handshake coverage,
  independent-convergence detection, RCO coverage, finding-quality
  metrics, and bridge_classify regression-class distribution. Used
  in the 2026-05-12 orchestrator design retrospective.
* **`tools/gen_gadget_bootstrap_kit.py`** — deterministic generator
  for `configs/bootstrap_kit/GADGET.yaml` with sha256-anchored
  signature_hash per ADR-062 BSK-004. First profile kit to ship.

## Operator action required before stable enable

1. **D1 PII-history scrub decision**. The release gate notes a
   blocked operator-only item: rewriting git history to remove
   pre-redaction PII. This requires force-push to `main` and is the
   operator's call, not Claude/Codex'.
2. **Bootstrap-kit sign-off**. `configs/bootstrap_kit/GADGET.yaml`
   carries `signed_off_by: pending_operator_review_v3.12.0`. Per
   BSK-007 the BootstrapKitLoader will reject this kit until the
   operator replaces that field with an explicit signer id +
   ISO8601 timestamp. (BootstrapKitLoader implementation is the
   Codex lane; it lands separately during the soak window.)
3. **Fresh-subject evidence and soak**. The historical May 10–24 calendar
   window does not prove elapsed runtime of a September source. Freeze the
   final source subject `S`, obtain its CI and runtime evidence, and commit
   the allowed evidence-only outputs under the documented contract. Any
   change to the readiness policy needs an explicit operator disposition;
   old hours must not be relabeled as a fresh-subject soak.
4. **Integration dispositions**. The source PRs contain multiple recognized
   contributors; PR #1673 also touches operator-gated `README.md` and
   `pyproject.toml`. The composition preserves that history. Automated
   consensus refusal is not an authorization to bypass the merge rules.
5. **Torch scope signature**. The 2026-08-26 scope update in
   `docs/operator_inbox/torch-cuda-vs-cpu.yaml` remains unsigned.
6. **Pre-source evidence discipline**. Privacy and raw security receipts live
   inside `S`; they are not among the six permitted post-`S` evidence paths.
   The September receipt records the actual combined-tree host validation.
   If its attested source changes, revalidate before selecting a new `S`.

## Truth statements (BUSL / claim discipline)

This release:

* Does **not** claim AGI, consciousness, model superiority, or
  any threshold-of-intelligence benchmark.
* Reports cold-boot reduction as a measured number on the specific
  `bind_executors()` call path (6855 ms → 27 ms median), not a
  whole-system or "intelligence" metric.
* Confirms the 55-ADR substrate is **substrate**, not runtime: the
  contracts gate the schema, the implementations land one-by-one
  through future PRs (L54-reframed is the only impl that landed
  inside this release; the other 54 ADRs remain as pinned design
  intent until their implementation PRs are written, reviewed, and
  merged).
* States Docker `:latest` will remain `v3.8.0` until the explicit
  stable promotion at 2026-05-24 or later.
* Reports test results by tested version: the original composition
  `5fdf030a` passed 18,966 local tests with 61 skips. The corrected
  composition `1a6598c7` passed 469 affected/boundary tests and 87 privacy
  tests. The final candidate still requires its own full GitHub CI gate.
* Reports the September security evidence within its measured scope:
  Bandit at `fdbd0c3d` found HIGH 0 / MEDIUM 0 / LOW 232 across 614 files;
  the remaining LOW findings are not closed. OSV audited 113 exact lock pins
  with zero known vulnerabilities. The attested source trees/lock are
  unchanged in `1a6598c7`; the canonical receipt records provenance.
* Does **not** claim a completed fresh-subject soak, a container smoke,
  a stable release, or unbounded scaling. Host `SMOKE_OK` is host evidence.
  Learning, memory and future digital-twin work remain directions to validate,
  not capabilities established by these release tests.
